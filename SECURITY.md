# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities through GitHub's **Report a
vulnerability** feature on this repository's Security tab:

<https://github.com/fazi-gondal/video-downloader-mygo/security/advisories/new>

The repository owner must enable private vulnerability reporting before this
channel is available. Do not disclose suspected vulnerabilities in public issues,
pull requests, or discussions. If private reporting is unavailable, contact the
maintainer privately through GitHub before sharing technical details.

Please include the affected version, operating system, a concise description of
the security impact, and steps to reproduce using a safe test setup. Do not include
real credentials, cookies, private URLs, or other sensitive data. Avoid accessing
or modifying data that is not yours, and stop testing once the security impact is
clear.

## Supported versions

Please check whether the issue affects the latest release. Older releases may not
receive security fixes or backports; update to the latest release when practical.

## Scope

This project is a desktop application. Reports may concern the application,
packaging and update workflows, or the handling of bundled tools and user data.
Issues in third-party tools such as yt-dlp and FFmpeg should also be reported to
their respective maintainers.
