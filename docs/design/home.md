# Home / Hero 设计说明

## 这一屏要完成的事

1. 让人一眼知道：粘贴一个链接，就能下载。
2. 提供第二条路：yt-dlp 解析不了的网页，可以用提取器。
3. 不解释实现，不展示功能清单，不卖弄。

首页不是落地页，是一个工作台。它应该安静、明确、一次只指一个方向。

## 设计原则

- **一条主轴**：标题 → 说明 → 输入 → 次要入口 → 支持站点。所有元素沿同一条中轴线排列。
- **一个焦点**：主色只出现在「解析」按钮和标题最后一个词上，其余保持墨色或灰。
- **用间距分组，不用卡片分组**：首页不使用卡片墙；分组靠垂直留白完成。
- **次要入口必须安静**：网页提取是 pill 形文字按钮，不与搜索框抢注意力。
- **展开不换页**：提取器从 pill 原地展开，标题和搜索框保持不动；内容变高时整页滚动，而不是重新排版。
- **中文排版优先**：标题不用英文句号；节奏靠词间距和字距，不靠标点。

## Tokens

### 颜色（沿用应用既有调色板）

| 名称 | 值 | 用途 |
| --- | --- | --- |
| Paper | `#f8f9ff` | 页面背景 |
| Surface | `#ffffff` | 输入框、pill、结果卡 |
| Ink | `#1a1c1e` | 标题第一个词、正文 |
| InkMuted | `#5f636b` | 说明、标题第二词、辅助文字 |
| Coral | `#ff5c49` | 主按钮、标题重音、提取器图标 |
| Hairline | `#d9dbe3` | 输入框与 pill 边框 |

### 字体

- 单一字体家族：系统中文字体（PingFang / 思源黑体回退）。
- 字阶：
  - 标题 30 / Bold / 行高 1.2
  - 说明 14 / Regular / 行高 1.6
  - 输入 15 / Regular
  - 次要入口 13 / Medium
  - 站点标签 11 / Medium / InkMuted
  - 站点名 12 / Regular / InkMuted

### 间距

4 的倍数：4 / 8 / 12 / 16 / 24 / 32 / 48。首页只用 12、16、24、32、48 五档。

### 尺寸

- 内容最大宽度：720
- 搜索框高度：56
- 主按钮高度：40
- 结果卡圆角：14；输入框圆角：12；pill 圆角：999
- 页面左右内边距：40（窄窗 20）

## 布局

收起状态（默认）：

```
                     提取   转换   掌控
              从你常用的平台下载、整理和转换媒体。

        ┌──────────────────────────────────────────┐
        │ 🔗   粘贴视频或播放列表链接…       [解析] │
        └──────────────────────────────────────────┘
                 ( 解析不了？用网页提取试试 )

                        支持的站点
            YouTube   TikTok   Instagram   X   ARY Plus
```

- 整组内容在可用高度内垂直居中；内容超过窗口时从顶部开始并滚动。
- 所有块水平居中，中线与搜索框中心重合。
- 标题与说明间距 12；说明与搜索框间距 32；搜索框与 pill 间距 16；pill 与站点区间距 36。
- 标题词间距 12，字距 0.5；不使用标点。
- 说明单行，最大宽度 520，超出换行。

展开状态：

```
                     提取   转换   掌控
              从你常用的平台下载、整理和转换媒体。

        ┌──────────────────────────────────────────┐
        │ 🔗   粘贴视频或播放列表链接…       [解析] │
        └──────────────────────────────────────────┘
                 ( 收起网页提取 )
        ┌──────────────────────────────────────────┐
        │ ✨   粘贴视频页面链接…             [解析] │
        └──────────────────────────────────────────┘
         适用于播放器配置以明文写在页面里的站点。

        ┌────────── 结果卡（720 宽）──────────────┐
        │ 页面标题                     2 个视频    │
        │ 全选   全不选                  已选 2 个 │
        │ ☑ 视频一   48:16 · HLS          复制    │
        │ ☑ 视频二   10:40 · HLS          复制    │
        │ 复制全部链接   全部下载      继续（2 个）│
        └──────────────────────────────────────────┘
```

- pill 原地变为「收起网页提取」，不移动。
- 面板与搜索框同宽，顶部间距 12。
- 面板高度从 0 展开到内容高度，200ms；内容同时从 0.4 透明度淡入到 1。
- 标题组的顶部偏移与面板同时长、同曲线地动画：收起时居中偏移，展开时固定 40。偏移不根据实时内容高度重算，否则收起时会先收面板、再重新居中，看起来像两段动画。
- 展开后标题仍保留；整页滚动，不切换到另一种布局。

## 状态与反馈

| 状态 | 表现 |
| --- | --- |
| 空闲 | 上面的收起布局 |
| 解析中（主链接） | 搜索框下方显示 spinner + 正在分析媒体…，标题保留 |
| 主链接失败 | 搜索框下方出现错误条，其中「用网页提取试试」把链接带入提取器 |
| 提取器解析中 | 面板内 spinner + 正在读取页面与播放器配置… |
| 提取器失败 | 面板内错误条，保留输入内容 |
| 提取结果 | 结果卡；默认全选；可复制、继续、全部下载 |
| 无结果 / 加密配置 | 面板内一句说明，不弹窗 |

## 动效

- 只有一处主动效：提取器面板的展开/收起（高度 200ms + 内容淡入）。
- 不对标题、说明、搜索框加入场动画。
- 系统减少动态时，高度与透明度直接到位。

## 可访问性

- 所有可点击元素有可见焦点；pill 与按钮可用 Tab 到达，Enter/Space 触发。
- 图标不是唯一信息：主题按钮有可读标签（后续补充）。
- 中英文都保证 720 宽下不截断；窄窗 800 时搜索框收缩，按钮保留。

## 文案

- 标题：提取 转换 掌控（中文无标点；英文 Extract. Convert. Master.）
- 说明：从你常用的平台下载、整理和转换媒体。
- 输入占位：粘贴视频或播放列表链接…
- 次要入口：解析不了？用网页提取试试 / 收起网页提取
- 站点标签：支持的站点

## 实现映射

- `dashboardHero`：Scroll + 最小高度 = 窗口高度 − 顶栏 44 − 页面上下内边距 32；内部 Column `AlignItems(Center)` + `Justify(Center)`。
- 三个分组各自成 Column，用上内边距控制节奏，不使用统一大 gap。
- `extractorCollapsible`：`ui.CollapsibleBase`，Trigger 为 pill，Panel 用 `Progress()` 控制透明度；面板宽度 = min(720, 窗口宽 − 侧栏 212 − 页面内边距 32 − hero 内边距 80)。
- 全部字符串走 i18n；尺寸与颜色取自 token。
